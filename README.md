# Dashboard de Anúncios de Carros

Interactive web dashboard for exploratory data analysis (EDA) of used car listings in the US market.

## Features
- Preview of the dataset
- Interactive histogram of vehicle mileage (odometer)
- Scatter plot of Price vs Mileage

## Tools & Technologies
- Python, Pandas
- Plotly Express
- Streamlit

## How to run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Context
Project developed during TripleTen Data Science Bootcamp
